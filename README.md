# Vocantis - Documentação do Projeto 📚

Repositório oficial dedicado exclusivamente à **documentação, diagramas, artefatos de gestão e relatórios** do projeto **Vocantis**.

---

## 🎯 Sobre o Projeto
O **Vocantis** é uma plataforma voltada à **orientação vocacional, autoconhecimento e direcionamento para cursos** (com foco especial nas ETECs e FATECs). O objetivo é auxiliar estudantes e jovens a encontrarem sua trajetória profissional com base em seus interesses, perfil e habilidades.

---

## 📂 Estrutura do Repositório

* **`/diagrams`**: Contém os fluxos de processos (BPMN), Estrutura Analítica do Projeto - EAP (WBS) e diagramas de modelagem.
* **`/personas`**: Apresentações, mapa da jornada do usuário e documentação das proto-personas.
* **`/sprint-docs`**: Planejamentos de ciclos, definições de metas SMART e acompanhamento de entregas.
