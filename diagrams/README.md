# Diagramas e Modelagem - Projeto Vocantis 📊

Esta pasta armazena os diagramas de processos, modelagem estrutural e artefatos visuais de planejamento do projeto **Vocantis**.

---

## 🧭 Conteúdo da Pasta

* **BPMN (Business Process Model and Notation):** Mapeamento dos fluxos de processos de orientação vocacional, cadastro de usuários e recomendação de cursos da plataforma.
* **EAP (Estrutura Analítica do Projeto / WBS):** Decomposição hierárquica do escopo do Vocantis em entregáveis menores gerenciáveis para as Sprints.
* **Diagramas UML / Arquitetura:** Modelos visuais auxiliares para o desenvolvimento da aplicação web.

---

## 📂 Como enviar seus arquivos
Caso você tenha os arquivos exportados (como imagens `.png`, `.jpg`, arquivos `.bpmn` ou PDFs dos diagramas criados em ferramentas como Bizagi, Lucidchart ou Draw.io), basta salvá-los diretamente dentro desta pasta `diagrams/` no repositório.
